# FD-04 — La vista pública todavía no guarda nada

**Estado:** Temporal · **Fecha:** 2026-09-10

**Por qué:** todavía no existe el backend para guardarlo, así que al confirmar solo se muestra una
pantalla de éxito. No hay envío real.

el submit deja de ser simulado y se guarda de verdad.
