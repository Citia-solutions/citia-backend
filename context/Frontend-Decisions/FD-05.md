# FD-05 — El flujo público vive junto al del panel (por ahora)

**Estado:** Tomada · **Fecha:** 2026-09-10

**Por qué:** el código del enlace público está en la misma carpeta que el modal del panel
(`features/crear-cita`). Funciona, pero mezcla dos cosas que a futuro pueden separarse.

**Qué implica:** se puede separar más adelante, cuando el flujo público tenga su propio backend y
contrato. Por ahora se deja así para no reordenar sin ganar nada visible.
