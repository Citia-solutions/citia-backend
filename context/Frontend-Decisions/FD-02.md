# FD-02 — Cada profesional comparte su propio enlace

**Estado:** Tomada · **Fecha:** 2026-09-10

**Por qué:** el enlace es personal e identifica a un profesional concreto, así que no hace falta una
lista para elegir doctor. Cada profesional comparte el suyo.

**Qué implica:** la dirección del enlace tiene que llevar "quién es" el profesional. Hoy eso no está
listo en el backend. Como consecuencia, la vista pública no tiene un selector de profesionales.

**Pendiente:** implementar la identificación pública del profesional (lo que el backend llama
ADR-08).
